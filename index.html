FAQ

How do I set it up?
Create a repo on GitHub or GitLab, create a Personal Access Token (repo scope on GitHub; api + write_repository on GitLab), then in the extension go to Settings and enter your repo and token.
Is my data secure?
Yes. Articles are stored only in your Git repository. Your token stays in your browser and is never sent to our servers. We don’t have access to your content.
Do I need Pro to save articles?
No. Saving to a single repo with the default structure is free. Pro adds multiple repositories, custom paths, and labels.
Where can I report bugs or ask for help?
Open an issue on GitHub. For purchase or account help, contact support at mystashmark.com.
